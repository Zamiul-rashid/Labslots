Email

{% if mail.on %}

Enrollment decisions are emailed to every member of the group. Sent from {{ mail.sender }} through {{ mail.host }}:{{ mail.port }}{% if mail.user %} as {{ mail.user }}{% endif %}. Each send and failure is in the Log.

{% else %}
Email is off. Groups still see each decision on their status page.

To turn it on, on the server in /opt/labslots:

  1. Set SMTP_HOST, SMTP_PORT, SMTP_USER and SMTP_FROM in .env. For a Google account: smtp.gmail.com, port 587, the account's address as user and sender.
  2. Put the password in secrets/hub/smtp_password (mode 400, owner uid 10001). For a Google account that is an app password, not the account password.
  3. Run docker compose up -d labslots, then come back here and send a test email.
